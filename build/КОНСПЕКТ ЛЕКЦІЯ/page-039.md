Покажемо, що системи (1.38) і (1.39) еквівалентні (збігаються множини їх розв'язків).
Для цього розглянемо систему
$$Bx=b\qquad(1.40)$$
$\forall x$, що задовольняє (1.40) виконується рівність
$$x^TB^TBx=b^Tb=\sum_{i=1}^{n}b_i^2\qquad(1.41)$$
♦*Показати самим*.
*Доведення*.
Нехай є вектор $x$, для якого виконується (1.38). Тоді для нього автоматично виконується (1.39).
Беремо вектор $x$, для якого виконується (1.39), але не виконується (1.38). Тоді для цього вектора виконується (1.40), де $b\ne\overline{0}$. Тоді для цього вектора виконується (1.41), що суперечить (1.39).
Тому еквівалентність (1.38) і (1.39) доведено.

*Примітка.* З лінійної алгебри відомо, що для будь-якої прямокутної матриці $B$ матриця $B^TB$ є невід'ємно означеною.
Розглянемо наступні матриці:
$$M_1=\begin{matrix}&m&n\\m&-E&B\\n&\mu B^T&A\end{matrix}\quad\mu>0\quad(n+m)\times(n+m)\qquad M_2=\begin{matrix}&m&n\\m&E&B\\n&0&E\end{matrix}$$
♦*Показати самим*, що матрицю $M_1$ можна множити блочно на матрицю $M_2$, тобто вважати при множенні блоки числами.
$$M_3=M_1M_2=\begin{pmatrix}-E&0\\\mu B^T&A+\mu B^TB\end{pmatrix}.$$
Але $\det M_3=\det M_1$.

*Примітка.* $\det M_sM_t=\det M_s\cdot\det M_t$, тому $\det M_3=\det M_1\cdot\underbrace{\det M_2}_{=1}$.
$$\det M_3=(-1)^m\det(A+\mu B^TB).$$

Нехай $\det\begin{pmatrix}0&B\\B^T&A\end{pmatrix}\ne0$
Розглянемо матрицю $M_1$. Завжди існує $\mu^*>0$, що $\forall\mu\ge\mu^*$ знак $\det M_1$ дорівнює знаку $\det\begin{pmatrix}0&B\\B^T&A\end{pmatrix}$.

Дійсно, $\det M_1=\mu^m\det\begin{pmatrix}-\frac{1}{\mu}E&B\\B^T&A\end{pmatrix}$.
Таким чином отримали першу умову:
Якщо $\det\begin{pmatrix}0&B\\B^T&A\end{pmatrix}\ne0$, то перший головний мінор матриці $A+\mu B^TB$ додатній $\forall\mu\ge\mu^*$, якщо знак $\det\begin{pmatrix}0&B\\B^T&A\end{pmatrix}$ збігається зі знаком $(-1)^m$.
Дійсно, $\det M_3=\det M_1$, а знак $\det M_3$ = знаку $\det M_1$.
