**Основні поняття:**

Умова поповнення (reinforcement); правило з підрахуванням балів; спроможність по Кондорсе; теорема Янга; маніпуляція профілем; неманіпульоване правило; профіль уподобань; підсилення/підйом кандидата; строга монотонність; «умова (2)» (стабільність переможця за фіксації відносних позицій); аксіома незалежності (Arrow IIA); Парето-оптимальність; P-вирішальна коаліція; правило диктатора; нестійкість більшості; незмінність переможця Кондорсе під маніпуляціями.

**Виклад основного матеріалу**

**Умова поповнення**

**Означення 4.4.** Довільне правило колективного голосування задовольняє умові поповнення, якщо для будь-якого профілю (таблиці) для нього виконується наступне. Нехай голосує $N_1$ агентів, таблиця $(u_1)$ і переможець $a$. Нехай голосує $N_2$ агентів, таблиця $(u_2)$ і переможець $a$. Тоді, якщо голосують $N_1\cup N_2$ агентів, таблиця $(u_1u_2)$, то переможець $a$.

♦*Довести самим*, що будь-яке правило с підрахуванням балів задовольняє умові поповнення.

**ТЕОРЕМА 4.2. (Янга)**
Будь-яке правило колективного голосування спроможного по Кондорсе не задовольняє умові поповнення.
*Доведення*.
Якщо профіль $(u_1)$ такий, що $a$ переможець по Кондорсе, по $(u_2)$ $a$ переможець по Кондорсе, то по профілю $(u_1,u_2)$ $a$ переможець по Кондорсе (♦*довести це самим*).
Беремо довільне правило голосування спроможне по Кондорсе. Голосує $n_1$ агентів, профіль $(u)$ і $a$ – переможець, але він не є переможцем по Кондорсе. Тобто існує такий претендент $b$, за якого в таблиці віддали б (в порівнянні з $a$) $m$ голосів, де $m>\frac{n}{2}$.
Нехай голосують ще $n_1$ агентів, таблиця $(u)$, а також є переможцем.
Нехай голосують $n_1+n_1$ агентів, таблиця $(uu)$. Якщо виконується умова поповнення, то переможець знову $a$.
Нехай голосують ще $2m+n_1$ ($2m>n_1$) агентів і профіль

| | $n_1$ | $n_1$ | $2m$ | $n_1$ |
|---|---|---|---|---|
| | $u$ | $u$ | $a$ | $b$ |
| | | | $b$ | $a$ |
| | | | … | … |
