Є узагальнений споживач, що споживає вектор продуктів $x=\begin{pmatrix}x_1\\\vdots\\x_n\end{pmatrix}$.

При фіксованому $x$, $g(x)$ – це корисність узагальненого споживача від споживання вектора продуктів $x$.
// Як отримати $g_0$, але при цьому затратити $min$. //
*Примітка 1*. За межами курсу залишається побудова функції $g(x)$. Вважається що вона відома.
*Примітка 2*. У ринкових моделях макроекономіки розглядається два суб'єкти: узагальнений виробник і узагальнений споживач.
// Внутрішня рівновага: поведінка виробника збігається з поведінкою споживача //
Запишемо умови множників Лагранжа 1-го роду на оптимальні розв'язки задачі:
$$L(x)=p^Tx-\lambda(g(x)-g_0),$$
$$g(x)-g_0=0$$
$$p_i-\lambda g_i=0,i=\overline{1,n};$$
$$\lambda=\frac{p_i}{g_j}>0\qquad(1.54)$$

// в другому рівнянні замість $g_i(x)$ запишемо просто $g_i$//
В моделі (1.53) будемо неперервно змінювати ціну $n$-го продукту $p_n$. Зрозуміло, що буде неперервно змінюватись і оптимальне рішення задачі (1.53). Але оптимальний розв'язок задачі (1.53) як функція $p_n$ буде задовольняти рівнянням (1.54).
Для дослідження якісних властивостей (1.53) як функція $p_n$, продиференціюємо оптимальний розв'язок задачі (1.53), що задовольняє (1.54).
Беремо похідні (по складному аргументу):
$\sum_{i=1}^{n}g_i\frac{dx_iP(n)}{dp_n}=0;$

$$-\frac{d\lambda P(n)}{dp_n}g_i-\lambda P(n)\sum_{j=1}^{n}g_{ij}\frac{dx_jP(n)}{dp_n}=\begin{pmatrix}0\\0\\\dots\\-1\end{pmatrix},i=\overline{1,n}.$$

Остання система після еквівалентного перетворення:
$$\frac{1}{\lambda P(n)}\cdot\frac{d\lambda P(n)}{dp_n}g_i+\sum_{j=1}^{n}g_{ij}\frac{dx_jP(n)}{dp_n}=\begin{pmatrix}0\\0\\\dots\\\frac{1}{\lambda P(n)}\end{pmatrix}i=\overline{1,n}.$$
