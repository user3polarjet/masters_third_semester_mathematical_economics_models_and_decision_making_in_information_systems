У цього профілю по довільному правилу спроможному по Кондорсе переможець $a$, бо він по цій таблиці є переможцем по Кондорсе (♦*показати самим*).
Покажемо, що якщо голосують $n_1+n_1+2m+n_1$ з профілем

| | $n_1$ | $n_1$ | $2m$ | $n_1$ |
|---|---|---|---|---|
| | $u$ | $u$ | $a$ | $b$ |
| | | | $b$ | $a$ |
| | | | … | … |

довільне правило спроможне по Кондорсе видає переможцем $b$, тому що по цьому профілю $b$ є переможцем по Кондорсе.
Порівнюємо $a$ і $b$ попарно з усіма претендентами. В найгіршому випадку за $a$ і $b$ віддають $2m+n_1$ голосів, а за будь-якого іншого претендента в найкращому випадку $n_1+n_1$ голосів. $2m+n_1>n_1+n_1$. $a$ і $b$ попарно виграють у будь-якого іншого претендента.
Порівнюємо $a$ і $b$. За $b$ у порівнянні з $a$ віддано $2m+n_1$, а за $a$ в порівнянні з $b-2n_1-2m+2m$.
$$2m+n_1>2n_1-2m+2m$$
Звідки $b$ – переможець по Кондорсе і для будь-якого правила спроможного по Кондорсе.

**Неманіпульовані правила голосування**

Нехай $A$ – множина претендентів, з яких обирається переможець. Кількість їх обмежена. Нехай $L(A)$ – множина всіх можливих профілів одного агента, що є повним порядком. Повний порядок $i$-того агента формально будемо задавати функцією переваги $u_i(\cdot)$, аргументом якої претендент для порівняння.
Якщо, наприклад, $u_i(a)>u_i(b)>u_i(d)$ – це означає, що стовпчик $i$-го агента
$$\begin{vmatrix}a\\b\\d\\\vdots\end{vmatrix}.$$
Літерою $u$ і $v$ будемо називати самі таблички.
Таким чином множина $L$ – множина всіх можливих стовпчиків, що задають строгий порядок будь-якого агента.
$N$ – кількість агентів.
$L(A)^N$ – всіх можливих різних таблиць $u$, кожний стовпець якої задає повний порядок.
Правило голосування формально задається $S(u)=a\in A,a$ - переможець.
**Означення 4.5.** Довільне правило колективного голосування зветься неманіпульованим, якщо для нього виконується $\forall u\in(L(f))^Nu_i(S(u))\ge u_i(S(v_i,u_{-i}))\forall v_i\in L(A)$.
Таблиця $v_i,u_{-i}$ отримана з таблиці $u$ заміною стовпця $u_i$ на стовпець $v_i$.
Еквівалентний запис: $v_i(S(v_i,u_{-i}))\ge v_i(S(u_i,u_{-i}))$.
