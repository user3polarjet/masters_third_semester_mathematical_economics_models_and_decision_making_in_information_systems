Лекція 19. Правила голосування спроможні по Кондорсе. Правило
Копленда. Правило Сімпсона
План лекції
1. Обмеження правила відносної більшості (приклад Кондорсе, “профілі”
вподобань).
2. Переможець за Кондорсе: означення, коли може не існувати.
3. Правила з підрахуванням балів: Борда та узагальнення; ідея теореми
Фішберна.
4. Правило Копленда: підрахунок попарних перемог/поразок, інтерпретація.
5. Правило Сімпсона (minimax): максимізація найменчої попарної підтримки.
6. Властивості правил: “спроможність по Кондорсе”, оптимальність по Парето,
монотонність.
7. Практичні зауваги: коли застосовувати Копленда/Сімпсона, як розв’язувати
нічиї.
Основні поняття:
Профіль уподобань; правило відносної більшості; переможець за Кондорсе;
парадокс Кондорсе; правило Борда; узагальнені бальні правила (scoring rules);
теорема Фішберна (несумісність із Кондорсе у деяких профілях); правило
Копленда; правило Сімпсона (minimax); спроможність по Кондорсе;
оптимальність по Парето; монотонність; попарні порівняння; підрахунок
підтримки.
Виклад основного матеріалу
Розглянуті далі правила голосування не використовуються для голосування,
але є конструктивними при роботі експертів, коли група експертів колективно
обирає кращий з проектів.
