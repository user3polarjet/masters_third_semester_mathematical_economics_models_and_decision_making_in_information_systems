Правило голосування по Борду узагальнили як правило голосування з підрахуванням балів.
Правило: кожен агент найгіршому претенденту приписує $S_0$ балів, наступному $S_1$ балів, і так далі, найкращому $S_{P-1}$ балів. $S_0\le S_1\le\dots\le S_{P-1},S_0<S_{P-1}$.

До речі, правило відносного голосування є частковим випадком правила с підрахуванням балів $S_0=S_1=\dots=S_{P-2}=0.S_{P-1}=1$

Переможець по Кондорсе і переможець по правилу голосування с підрахуванням голосів – це принципово різні правила.
Це підкреслює наступна теорема.

**ТЕОРЕМА 4.1 (Фішберна)**
Існують такі індивідуальні переваги (профілі), коли переможець по Кондорсе принципово не може бути переможцем по будь-якому правилу голосування з підрахуванням голосів (балів).
*Доведення*.
Фішберн довів свою теорему на двох прикладах.
Один з них (перший):

| бали ↓ | 3 | 2 | 1 | 1 |
|---|---|---|---|---|
| $S_2$ | c | a | a | b |
| $S_1$ | a | b | c | c |
| $S_0$ | b | c | b | a |

$S_0<S_1<S_2$  (7 агентів, 3 претенденти)
// другий приклад Фішберна – 17 претендентів; $S_0\le S_1\le S_2\le\dots\le S_{16}$, $S_0<S_{16}$; розглядається аналогічно //
Шукаємо переможця по Кондорсе:
$c:a\ (4:3)$
$c:b\ (4:3)$
$c$ – переможець по Кондорсе.
Але це принципово не може бути переможцем по правилу з підрахуванням балів, бо $a$ завжди краще $c$.
Покажемо це.
$$a:3S_2+3S_1+S_0S_1$$
$$c:3S_2+3S_1+S_0S_0\qquad S_1>S_0\Rightarrow a\ краще\ c$$

**Правила голосування спроможні по Кондорсе**

**Означення 4.1.** Правило голосування є спроможним по Кондорсе, якщо воно завжди задає переможця, і, якщо профіль (таблиця) такий, що в ньому існує переможець по Кондорсе з будь-яким правилом голосування з переможцем по Кондорсе, то переможець є переможець по Кондорсе.
