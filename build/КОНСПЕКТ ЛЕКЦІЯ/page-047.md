**Контрольні запитання**

1. У чому ідея методу множників Лагранжа 1-го роду для задачі з рівняннями-обмеженнями? Які рівності необхідно виконати в точці кандидата?
2. Що таке «кваліфікація обмежень» і для чого потрібен повний ранг градієнтів обмежень у точці розв'язку?
3. Як економічно інтерпретують множники Лагранжа (тіньові ціни / маржинальна вартість послаблення обмеження)?
4. Чому перших умов (стаціонарності) недостатньо для висновку про мінімум/максимум?
5. Що таке обрамлена матриця (bordered Hessian) для задачі з m рівняннями-обмеженнями? Які блоки вона містить?
6. Сформулюйте словесно ознаку локального мінімуму через знаки послідовності провідних мінорів обрамленої матриці (яку саме послідовність перевіряємо).
7. Як змінюється «знакове правило» для локального максимуму?
8. Як пов'язана перевірка другої умови з тестом додатності квадратичної форми на дотичному підпросторі (зв'язок із лекцією 6)?
9. У чому особливість і спрощення у випадку одного обмеження; як виглядає «обрамлена матриця» тоді?
10. Назвіть типові помилки під час застосування методу (наприклад, ігнорування рангу, плутанина зі знаком у «знаковому правілі», перевірка на невірному підпросторі).

**Питання для самостійного опрацювання (СРС)**

1. Для простої задачі з двома змінними та одним обмеженням:
	a. – запишіть стаціонарні умови 1-го роду;
	b. – побудуйте обрамлену матрицю;
	c. – перевірте знакове правило для мінімуму/максимуму;
	d. – звірте висновок із геометричною інтерпретацією.
2. Покажіть еквівалентність двох підходів другої умови:
	a. через обрамлену матрицю;
	b. через додатність/від'ємність квадратичної форми на дотичному підпросторі (використати логіку з лекції 6).
3. Розгляньте випадок лінійної цільової функції та одного нелінійного обмеження: випишіть Гессіан обмеження, побудуйте відповідну обрамлену матрицю й сформулюйте необхідні знакові умови для мінімуму.
