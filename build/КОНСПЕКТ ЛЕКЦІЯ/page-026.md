$$y=\begin{pmatrix}y_1\\y_2\\\vdots\\y_n\end{pmatrix}.$$
$y_j$ – кількість одиниць того продукту, який виробляє $j$-та технологія, тобто інтенсивність роботи $j$-тої технології.
Нехай на продаж треба випустити напівдодатний вектор $c$, тоді модель має вигляд:
$$\hat{A}y=c$$
$$y_j\ge0,j=\overline{1,n}$$
Введемо вектор однорідної праці $a_0$.
$a_{0j}$ – це кількість одиниць однорідної праці, яку треба витратити для виробництва того продукту, який випускає $j$-та технологія.

**Поставимо задачу.** Для заданого вектора продуктів на продаж $c$ знайти інтенсивність роботи технологій, якій відповідає мінімум трудових затрат.
Ця задача записується як задача лінійного програмування (1.1) (у канонічній формі):
$$\min_y a_0^Ty$$
$$\hat{A}y=c$$
$$y_j\ge0,j=\overline{1,n}\qquad(1.1)$$
$a_0^Ty$ – кількість узагальненої праці, яку треба витратити, щоб випустити на продаж вектор продуктів $c$.
Для спрощення подальшого аналізу технології матриці $\hat{A}$ групуємо так: спочатку йдуть стовпчики, які відповідають технологіям, що випускають перший продукт, далі – другий...
Розглядаємо випадок, коли довільний базис $\hat{A}_B$ задачі лінійного програмування (1) має вигляд $\hat{A}_B=(E-A)$, де $A$ – технологічна матриця розмірності $[n\times n]$ продуктивної ВМЛ з нульовою головною діагоналлю, $E$ – одинична діагональна матриця розмірності $[n\times n]$.
Для ВМЛ $\lambda_A^*<1$, тоді матриця $\hat{A}_B^{-1}$ додатна. Всі базисні змінні більше нуля.
Тобто в оптимальному розв'язку для виробництва вектора продуктів на продаж $c$ використовуються $n$ різних технологій, що виробляють $n$ різних продуктів. Інші технології на цьому розв'язку мають нульову інтенсивність.

**ТЕОРЕМА 1.6.** Нехай для вектора продуктів на продаж $c$ знайшли оптимальний базис $\hat{A}_B^{ОПТ}$. Тоді він (базис) залишається оптимальним для довільного напівдодатного вектора продуктів $c$.
Іншими словами: для деякого вектора продуктів на продаж $c$ знайшли оптимальні $n$ технологій, яким відповідає $\min_y a_0^Ty$. Ці технології залишаються оптимальними по цьому критерію для довільного напівдодатного вектора $c$.
