Підставляємо у рівняння бюджетного обмеження:
p1x1 + p2x2 + p3x3 = B,
p1x1 + p2 ∙ (x1p1 / p2) + p3 ∙ (x1p1 / p3) = B,
p1x1 + p1x1 + p1x1 = B,
3p1x1 = B,
x1 = B / 3p1 = 3000 / (3 ∙ 20) = 3000 / 60 = 50,
x2 = x1p1 / p2 = 50 ∙ 20 / 40 = 1000 / 40 = 25,
x3 = x1p1 / p3 = 50 ∙ 20 / 10 = 1000 / 10 = 100.
