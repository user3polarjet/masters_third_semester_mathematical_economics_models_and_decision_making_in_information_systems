2. За критерієм Фішера з надійністю 0,95 оцініть адекватність регресії статистичним даним. Якщо економетрична модель адекватна статистичним даним, то знайдіть значення факторів, при яких прибуток комерційного підприємства буде максимальним.

Перевіримо адекватність моделі експериментальним даним. Для цього знайдемо значення критерію Фішера на рівні значимості $\alpha=0.05$ та степенями свободи:

$n=10$ (кількість спостережень);  
$m=5$ (кількість факторів + коефіцієнт);  
$k_1=m-1=5-1=4$;  
$k_2=n-m=10-5=5$;  
$F_{кр}=5,19$ (із таблиці).

Так як отриманий $F=20.431>F_{кр}=4.26$, то отримана модель достовірна з ймовірністю 0.95.

Отже, отриману модель можна використовувати для подальшого аналізу впливу факторів $X_1$ та $X_2$ на обсяг прибутку комерційного підприємства. Щоб визначити максимальний прибуток, обчислимо спочатку критичні точки нашої функції $Y$.

Для цього обчислимо частинні похідні та прирівняємо їх до нуля:

$$\frac{\partial Y}{\partial X_1}=a_1+2a_2X_1=0.4398-2\cdot0.0039\cdot X_1=0;$$

$$\frac{\partial Y}{\partial X_2}=a_3+2a_4X_2=0.4773-2\cdot0.0032\cdot X_2=0.$$

$$X_1=-\frac{a_1}{2a_2}=56.18904;$$
