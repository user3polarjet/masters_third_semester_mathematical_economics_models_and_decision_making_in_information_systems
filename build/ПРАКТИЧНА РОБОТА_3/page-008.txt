Підставимо знайдені границі корисності товарів:
(x2x3 / 2x1)0.5 / (x1x3 / 2x2)0.5 = p1 / p2 ,
(x1x3 / 2x2)0.5 / (x1x2 / 2x3)0.5 = p2 / p3 ,
(x1x2 / 2x3)0.5 / (x2x3 / 2x1)0.5 = p3 / p1 .
Спрощуємо:
((x2x3 ∙ 2x2) / (2x1 ∙ x1x3))0.5 = p1 / p2 ,
((x1x3 ∙ 2x3) / (2x2 ∙ x1x2))0.5= p2 / p3 ,
((x1x2 ∙ 2x1) / (2x3 ∙ x2x3))0.5 = p3 / p1 .
Скорочуємо множники, отримуємо:
x2 / x1 = p1 / p2 ,
x3 / x2 = p2 / p3 ,
x1 / x3 = p3 / p1 .
Виразимо x2 та x3 через x1:
x2 = x1p1 / p2 ,
x3 = x1p1 / p3 .
Підставляємо у рівняння бюджетного обмеження:
p1x1 + p2x2 + p3x3 = B,
p1x1 + p2 ∙ (x1p1 / p2) + p3 ∙ (x1p1 / p3) = B,
p1x1 + p1x1 + p1x1 = B,
3p1x1 = B,
x1 = B / 3p1 = 3000 / (3 ∙ 20) = 3000 / 60 = 50,
x2 = x1p1 / p2 = 50 ∙ 20 / 40 = 1000 / 40 = 25,
x3 = x1p1 / p3 = 50 ∙ 20 / 10 = 1000 / 10 = 100.
