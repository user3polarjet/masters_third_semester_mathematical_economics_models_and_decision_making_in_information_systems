1) Побудуйте криву байдужості в Excel, яка проходить через точку (3, 1):
Виразимо 𝑋2 через 𝑋1 та U:
𝑈 = (2𝑋1 + 1)(𝑋2 + 3),
𝑈 / (2𝑋1 + 1) = 𝑋2 + 3,
𝑋2 = 𝑈 / (2𝑋1 + 1) – 3.
U в цьому випадку є константою, знайдемо її підставивши значення 3 та 1 у
початкову формулу:
𝑈 = (2𝑋1 + 1)(𝑋2 + 3) = (2 ∙ 3 + 1) ∙ (1 + 3) = 7 ∙ 4 = 28.
Отже, маємо наступну формулу:
𝑋2 = 28 / (2𝑋1 + 1) – 3.

2) Знайдіть граничну корисність кожного різновиду товарів:
Гранична корисність товару показує, на скільки зростає корисність, якщо
кількість товару зростає в малому обсязі.
Гранична корисність товару X1:
∂U / ∂X1 = ∂((2𝑋1 + 1)(𝑋2 + 3)) / ∂X1 = 2 ∙ (𝑋2 + 3) = 2𝑋2 + 6.
Гранична корисність товару X2:
∂U / ∂X2 = ∂((2𝑋1 + 1)(𝑋2 + 3)) / ∂X2 = (2𝑋1 + 1) ∙ 1 = 2𝑋1 + 1.
3) Знайдіть норму заміщення другого товару першим:
Норма заміщення показує, скільки необхідно одиниць другого товару, щоб
замінити малий обсяг першого товару, який вибув.
Норма заміщення другого товару першим:
MRS = ∂X1 / ∂X2 = (∂U / ∂X2) / (∂U / ∂X1) = (2𝑋1 + 1) / (2𝑋2 + 6).
